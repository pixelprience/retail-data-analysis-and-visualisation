# Retail Data Analysis and Visualisation

## Overview

This project was completed as part of the Tata Data Visualisation Virtual Experience Program.

The objective was to analyse over 500,000 retail transaction records and generate actionable business insights using data visualisation techniques.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualisation

## Key Insights

### Revenue Trends

Revenue fluctuated throughout 2011 and reached its highest level in September, indicating seasonal sales patterns.

### Top Performing Countries

Netherlands, EIRE and Germany generated the highest revenue outside the United Kingdom.

### Top Customers

A small number of customers generated a significant proportion of total revenue, highlighting opportunities for customer retention strategies.

### Product Demand

Demand was concentrated within Western Europe, particularly in the Netherlands, Germany and France.
